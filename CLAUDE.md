# Repo

Este repo tiene dos partes:
- `remotion-motion-graphics/`: el skill público de Remotion (en inglés).
- `mnc-reels/`: el editor de reels de Manuel NoCode (MNC).

## Pedidos de reels de Manuel NoCode

Si el usuario pide un reel, un video de Manuel, o pega una liga de Drive con un guion:
1. Trabaja dentro de `mnc-reels/`.
2. Lee primero `mnc-reels/INSTRUCCIONES.md` (fuente de verdad), `mnc-reels/CLAUDE.md` y `mnc-reels/README.md` (flujo y scripts).
3. Sigue el flujo de la sección 3 de INSTRUCCIONES.md sin pedir que te repitan las instrucciones.
4. Responde siempre en español, claro y breve.

El usuario solo manda: liga de Drive con la grabación, guion con storyboard, grabaciones de pantalla
(si hay) y frase de portada (puede venir después). La transcripción la sacas tú del video.
